# Rep regression pass — September 12, 2026

## Findings corrected

1. Date and time inputs inside the workshop's shadow root could display entered values without updating React state. Task saves lost their dates; the deal demonstration could remain unable to save. The native controls now handle the input event as well as change.
2. Saved tasks and deals could not be corrected. Their existing record labels now reopen the original form for editing; saving updates that item without adding a duplicate. The original server grader remains authoritative.
3. Nurture and closing-commitment prompts appeared twice when authored worksheet keys differed from live activity keys. The runtime reuses the authored field.
4. Repeated field names such as correction and retry shared browser storage across separate activities. Draft keys now include the stable slide ID; existing browser notes remain readable.
5. Downloaded notes omitted fields added from activity definitions. Downloads now include those fields and keep separate practice rounds separate.
6. Repair controls relied on pointer-event styling for the diagnosis lock. The controls are now disabled/read-only and save handlers also enforce the lock.
7. Failed quiz results used a dark background with dark text; answer-review colors also lacked contrast. These now use readable workshop colors. The result return button accurately says Back to training.
8. The custom-module manager existed but had no opening button. Manage modules is restored for the existing leader/admin role gate.
9. Timer commands stayed enabled after session end. They are now disabled with the other teaching controls.
