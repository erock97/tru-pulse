How this report is calculated

Cohort: Current source matches the selected source, created between the selected dates in the selected timezone. Creation is not assignment. Source and agent ownership are the current API values.

Milestones: Historical stage changes through the selected end date, counted once per lead per category. A stage named as the old stage also proves the lead occupied it before leaving. Moving backward never removes credit. A current stage alone does not invent a dated historical achievement.

Credit rule supplied by Eric: Offers earns Met with. Under Contract or Pending earns Met with and Offers. Closed earns all preceding production milestones. Nurture is independent. Derived credit keeps the supporting later event; it does not receive an invented earlier date.

Nurture now: Leads currently in Nurture from this cohort ÷ all leads in this cohort × 100. This uses the current snapshot, even when the selected reporting end date is historical. Milestone columns overlap and must not be added together.

Raw conversion: Distinct leads with historical Closed evidence through the selected end date ÷ all leads created in the selected cohort × 100. This is lead conversion, not a count of transactions. Incomplete history can understate this number.

Mapping: Met with Customer → Met with; Submitting Offers → Offers; Under Contract and Pending → Under contract; Closed → Closed; Nurture → Nurture. Other stages remain visible in the record detail.

Coverage: The API included Trash. Deleted or inaccessible leads cannot be certified. Unrecognized history text remains visible as a parsing exception and is excluded from counts. This pilot groups by current owner; the user making a change is not assumed to be the assigned agent.
